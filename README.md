# MeanVC2 Desktop

Приложение для Windows 10/11, которое меняет голос с микрофона в реальном времени
по образцу другого голоса. Основано на [MeanVC2](https://github.com/ASLP-lab/MeanVC2)
с [дообучением для русского языка](https://huggingface.co/ytre0o0/MeanVC2-ru).

Программа позволяет:

- Записывать образцы голосов с микрофона или добавлять готовые аудиозаписи.
- Сохранять несколько голосов, прослушивать их и переключаться между ними.
- Выбирать микрофон и устройство вывода, включая виртуальные аудиоустройства.
- Регулировать громкость и видеть уровень звука и задержку обработки.
- Работать на процессоре **CPU** или видеокарте **NVIDIA с CUDA**.

Интерфейс полностью на русском языке. Звук обрабатывается на вашем компьютере;
после загрузки моделей подключение к интернету не требуется.

**Актуальная версия:** [скачать MeanVC2 Desktop](https://github.com/ytreeeeeeeeeeee/MeanVC2RuDesktop/releases/latest).
